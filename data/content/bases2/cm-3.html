Ce cours pose le vocabulaire de base des ensembles : comment décrire un ensemble, ce que signifie « appartenir » et « être inclus », l'ensemble des parties, puis les opérations (union, intersection, différence, complémentaire, produit cartésien) et enfin les mots sur un alphabet. Tout le reste des maths de L1 s'écrit avec ce langage.

1. Notions générales

1.1 Extension et compréhension

Intuitivement, un ensemble est une collection d'objets (les éléments de l'ensemble), deux à deux distincts. Pour se donner un ensemble, il y a deux façons :

  • Par extension : on donne la liste de tous les éléments de l'ensemble.
  • Par compréhension : on donne une propriété commune, satisfaite par tous les éléments de l'ensemble et par eux seulement.

En informatique — un type de données est un ensemble d'objets associés à une liste d'opérations ; déclarer le type d'une variable, c'est déclarer l'ensemble des valeurs qu'elle peut prendre. En Python : bool = { Vrai, Faux } ; int = les entiers ; float = les nombres à virgule flottante ; str = les chaînes de caractères ; list = les listes de longueur variable.

1.2 Règles basiques de fonctionnement

Relation d'appartenance

Il faut pouvoir dire si un objet appartient ou non à un ensemble. On note « \(x \in E\) » pour dire que \(x\) est un élément de \(E\) (on lit « \(x\) appartient à \(E\) »). L'ensemble \(E\) est précisément la collection des \(x\) qui vérifient \(x \in E\). Le contraire s'écrit \(x \notin E\).

Objets distincts

On peut distinguer deux éléments de \(E\), et \(E\) ne peut pas contenir deux fois le même élément. Répéter un élément ne change donc rien :

\[ \{0, 1, 2\} = \{0, 0, 1, 2, 1\} \]

Ensemble vide

Il existe un ensemble particulier, l'ensemble vide : celui qui ne contient aucun élément. Notation : \(\{\} = \varnothing\). Exemple : \(\{x \in \mathbb{R} \mid x^2 = -1\} = \varnothing\) (aucun réel n'a un carré négatif) ; de même { triangles rectangles équilatéraux } = \(\varnothing\).

Le paradoxe de Russell (digression) — Un ensemble peut être élément d'un autre ensemble, mais pas de lui-même. À la naissance de la théorie des ensembles, on envisageait « l'ensemble de tous les ensembles ». Fait : on ne peut pas. La « collection » de tous les ensembles n'est pas un ensemble.

Preuve. Supposons que la collection de tous les ensembles soit un ensemble, notons-le \(E\). Considérons \(A = \{x \in E \mid x \notin x\}\). Comme \(E\) contient tous les ensembles, \(A\) appartient à \(E\). Question : \(A \in A\) ?

  • Si \(A \in A\), alors par définition de \(A\), on a \(A \notin A\) : impossible.
  • Si \(A \notin A\), alors par définition de \(A\), on a \(A \in A\) : impossible.

Les deux cas sont contradictoires, donc \(E\) n'existe pas. On retient : un ensemble ne peut pas être élément de lui-même.

Complément — ce que la preuve établit strictement, c'est que « l'ensemble de tous les ensembles » n'existe pas ; « aucun ensemble n'est élément de lui-même » est la règle de fonctionnement qu'on en retient.

1.3 Patatoïdes, diagrammes de Venn

On représente un ensemble par une « patate » contenant ses éléments (diagramme de Venn) : ici \(A = \{-7, \text{Toulouse}, \text{café}, 18\}\). Le polycopié le fait de même pour { Pierre ; Paul ; Marie ; Julie ; Karim }.

2. Sous-ensembles

2.1 Inclusion

Définition — L'ensemble \(A\) est un sous-ensemble de l'ensemble \(B\) si tout élément de \(A\) est aussi un élément de \(B\) : \((x \in A \Rightarrow x \in B)\). Notation \(A \subset B\) (le polycopié écrit \(A \subseteq B\)) ; on dit aussi que \(A\) est inclus dans \(B\).
  • Remarque : pour tout ensemble \(A\), on a toujours \(\varnothing \subset A\) et \(A \subset A\) (aucun élément de \(\varnothing\) n'est à vérifier, donc l'implication est vraie).
  • Exemples : \(\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}\) ; \(\{1, 2, 3\} \subset \{0, 1, 2, 3\}\) ; \(\{1, 2\} \subset \{1, 2, 3\}\).
Définition — Les ensembles \(A\) et \(B\) sont égaux si \((A \subset B \text{ et } B \subset A)\), c'est-à-dire s'ils ont exactement les mêmes éléments. Notation \(A = B\). Autrement dit : \(A = B \Leftrightarrow (x \in A \Leftrightarrow x \in B)\).

Pour démontrer une égalité d'ensembles, on procède donc par double inclusion : on montre \(A \subset B\), puis \(B \subset A\) (ou par équivalences successives : voir CM 2).

2.2 \(\mathcal{P}(A)\), l'ensemble des parties de \(A\)

Définition — Soit \(A\) un ensemble. La collection de tous les sous-ensembles de \(A\) est un ensemble : on le note \(\mathcal{P}(A)\) et on l'appelle l'ensemble des parties de \(A\). « Une partie de \(A\) » est un synonyme de « un sous-ensemble de \(A\) ».

\[ \mathcal{P}(A) = \{B \mid B \subset A\} \qquad\text{avec}\qquad B \subset A \Leftrightarrow B \in \mathcal{P}(A) \]

  • Remarque : puisque \(\varnothing \subset A\), on a \(\varnothing \in \mathcal{P}(A)\) ; puisque \(A \subset A\), on a \(A \in \mathcal{P}(A)\). Toute partie de \(A\), y compris \(\varnothing\) et \(A\) elle-même, est un élément de \(\mathcal{P}(A)\).
  • Exemples : \(A = \{0, 1\} \Rightarrow \mathcal{P}(A) = \{\varnothing, \{0\}, \{1\}, A\} = \{\varnothing, \{0\}, \{1\}, \{0, 1\}\}\). Avec \(A = \{1, 2, 3\}\) : \(\mathcal{P}(A) = \{\varnothing, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}\) : 8 parties.
  • \(\mathcal{P}(\varnothing) = \{\varnothing\} \neq \varnothing\) : l'ensemble vide n'a qu'une partie (lui-même), donc \(\mathcal{P}(\varnothing)\) contient un élément et n'est pas vide. Image : un tiroir contenant un sac vide n'est pas vide, il contient bien un objet. De même \(\mathcal{P}(\mathcal{P}(\varnothing)) = \mathcal{P}(\{\varnothing\}) = \{\varnothing, \{\varnothing\}\}\).
Attention à ∈ et ⊂ — \(\in\) relie un élément à un ensemble, \(\subset\) relie deux ensembles. Avec \(A = \{0, 1\}\) : \(0 \in A\) mais \(\{0\} \subset A\) ; et \(\{0\} \in \mathcal{P}(A)\) alors que \(0 \notin \mathcal{P}(A)\). De même \(\varnothing \subset A\) et \(\varnothing \in \mathcal{P}(A)\).
Complément (vérifié) — si \(A\) a \(n\) éléments, \(\mathcal{P}(A)\) en a \(2^n\) (1, 2, 4, 8, 16, 32 pour \(n = 0\) à 5). Attention aux coquilles en recopiant : \(\mathcal{P}(\{0, 1\})\) contient \(\{0, 1\}\), pas \(\{1, 2\}\).

3. Opérations sur les ensembles

Ces opérations permettent de construire de nouveaux ensembles à partir d'ensembles donnés.

3.1 Union et intersection

Union — L'union (ou la réunion) des ensembles \(A\) et \(B\) est l'ensemble des éléments qui sont dans \(A\) ou dans \(B\). On la note \(A \cup B = \{x \mid x \in A \vee x \in B\}\).
Intersection — L'intersection de \(A\) et de \(B\) est l'ensemble des éléments qui appartiennent à \(A\) et à \(B\). On la note \(A \cap B = \{x \mid x \in A \wedge x \in B\}\). Deux ensembles sont dits disjoints (ou incompatibles) si \(A \cap B = \varnothing\).

PropriétéUnionIntersection
Idempotence\(A \cup A = A\)\(A \cap A = A\)
Commutativité\(A \cup B = B \cup A\)\(A \cap B = B \cap A\)
Associativité\(A \cup (B \cup C) = (A \cup B) \cup C\), noté \(A \cup B \cup C\)\(A \cap (B \cap C) = (A \cap B) \cap C\), noté \(A \cap B \cap C\)
Élément neutre / absorbant\(A \cup \varnothing = A\)\(A \cap \varnothing = \varnothing\) ; et \(A \cap \Omega = A\) si \(A \subset \Omega\) (\(\Omega\) = « univers »)

Distributivité

\[ (A \cup B) \cap C = (A \cap C) \cup (B \cap C) \qquad (A \cap B) \cup C = (A \cup C) \cap (B \cup C) \]

Ces égalités d'ensembles se lisent comme des égalités de logique (même « règle du jeu » que dans le chapitre sur le calcul propositionnel, CM 1) :

EnsemblesLogique
\(A \cup B\) (\(x \in A\) ou \(x \in B\))\(P \vee Q\)
\(A \cap B\) (\(x \in A\) et \(x \in B\))\(P \wedge Q\)
\((A \cup B) \cap C = (A \cap C) \cup (B \cap C)\)\((P \vee Q) \wedge R \Leftrightarrow (P \wedge R) \vee (Q \wedge R)\)
\((A \cap B) \cup C = (A \cup C) \cap (B \cup C)\)\((P \wedge Q) \vee R \Leftrightarrow (P \vee R) \wedge (Q \vee R)\)

3.2 Différence, différence symétrique, complémentaire

Différence — La différence entre l'ensemble \(A\) et l'ensemble \(B\) est l'ensemble des éléments de \(A\) qui ne sont pas dans \(B\). Notation \(A \setminus B\) (on lit « \(A\) privé de \(B\) ») : \(A \setminus B = \{x \in A \mid x \notin B\}\).

(Attention à la barre de « \(\notin\) » : c'est bien \(x \notin B\), pas \(x \in B\).)

Différence symétrique — Notée \(A \,\Delta\, B\), c'est l'ensemble des éléments qui sont dans \(A\) ou dans \(B\) mais pas dans les deux : \(A \,\Delta\, B = (A \cup B) \setminus (A \cap B)\) et aussi \(A \,\Delta\, B = (A \setminus B) \cup (B \setminus A)\).

Complémentaire — On fixe un ensemble \(\Omega\) appelé univers. Pour \(A \subset \Omega\), le complémentaire de \(A\) par rapport à \(\Omega\) est l'ensemble des éléments de \(\Omega\) qui ne sont pas éléments de \(A\) : \(\overline{A} = \Omega \setminus A\) (quand il n'y a pas d'ambiguïté). Il faut obligatoirement se placer dans un ensemble de référence pour parler de complémentaire.
Propriétés de la complémentation —
  • Involution : l'opération « prendre le complémentaire » appliquée deux fois redonne \(A\) : \(\Omega \setminus (\Omega \setminus A) = A\).
  • Lois de Morgan : \(\Omega \setminus (A \cap B) = \overline{A} \cup \overline{B}\) et \(\Omega \setminus (A \cup B) = \overline{A} \cap \overline{B}\) (le complémentaire échange \(\cup\) et \(\cap\), comme la négation échange « et » et « ou »).

3.3 Produit cartésien

Définition — Le produit cartésien des ensembles \(A\) et \(B\) (dans cet ordre) est l'ensemble des couples \((a, b)\) où \(a \in A\) et \(b \in B\) ; on le note \(A \times B\). Plus généralement \(A_1 \times A_2 \times \dots \times A_k\) est l'ensemble des \(k\)-uplets \((a_1, \dots, a_k)\) où \(a_i \in A_i\) ; si tous les \(A_i\) valent \(A\), on note \(A^k\).
  • Remarque : un couple \((a, b)\) n'est pas un ensemble : si \(a \neq b\), alors \((a, b)\) est distinct de \((b, a)\) (l'ordre compte, contrairement à \(\{a, b\} = \{b, a\}\)).
  • Exemple : \(\{1, 2, 3\} \times \{a, b\}\) a \(3 \times 2 = 6\) éléments : \((1,a), (1,b), (2,a), (2,b), (3,a), (3,b)\).
  • Exemple (couleurs RGB) : chaque couleur primaire (rouge, vert, bleu) prend une valeur entre 0 et 255 : une couleur est un élément de \([0 ; 255] \times [0 ; 255] \times [0 ; 255] = [0 ; 255]^3\). Avec des valeurs entières, cela fait \(256^3 = 16\,777\,216\) couleurs.

4. Exemple : l'ensemble des mots sur un alphabet fini

Un alphabet \(A\) est un ensemble fini dont les éléments sont appelés des lettres. Exemples : \(\{0, 1\}\) (alphabet binaire), \(\{a, b, c\}\) (trois lettres), \(\{a, \dots, z\}\) (26 lettres), { hello, word } (un alphabet à deux lettres : une « lettre » peut être un mot). N'importe quel ensemble fini convient.

  • Un mot défini sur \(A\) est une suite finie d'éléments de \(A\) : \(u = u_1 u_2 \dots u_n\) avec \(u_i \in A\). L'entier \(n\) est la longueur du mot, notée \(|u|\).
  • Le mot vide est noté \(\varepsilon\) : c'est le seul mot de longueur nulle.
  • On note \(A^*\) l'ensemble des mots sur \(A\), et \(A^+ = A^* \setminus \{\varepsilon\}\) l'ensemble des mots qui ne sont pas le mot vide.
  • Concaténation : pour \(u, v \in A^*\), \(w = u \cdot v\) est le mot de longueur \(|u| + |v|\) : \(w = u_1 \dots u_{|u|} v_1 \dots v_{|v|}\).
  • Puissance (définie par récurrence) : \(u^0 = \varepsilon\) et \(u^{n+1} = u \cdot u^n\).
  • Préfixe / suffixe : \(v\) est un préfixe de \(u\) s'il existe un mot \(w\) tel que \(u = v \cdot w\) ; \(v\) est un suffixe de \(u\) s'il existe \(w\) tel que \(u = w \cdot v\).
  • Un langage \(L\) sur \(A\) est un ensemble de mots sur \(A\), c'est-à-dire une partie de \(A^*\) : \(L \subset A^*\).
ExempleRésultat
Mots de longueur 0, 1, 2 sur \(A = \{a, b\}\)\(\varepsilon\) | \(a, b\) | \(aa, ab, ba, bb\) : il y a \(2^n\) mots de longueur \(n\)
Concaténation : \(ab \cdot cde\) (sur \(\{a, \dots, e\}\))\(abcde\), de longueur \(2 + 3 = 5\)
Puissance : \((ab)^3\) et \((ab)^0\)\(ababab\) et \(\varepsilon\)
Préfixes de \(abc\) / suffixes de \(abc\)\(\varepsilon, a, ab, abc\) / \(abc, bc, c, \varepsilon\)
Un langage\(L\) = { mots de \(A^*\) qui commencent par \(a\) } est une partie de \(A^*\)
Complément (vérifié) — le mot vide et le mot lui-même sont toujours préfixe et suffixe de \(u\). \(A^*\) est infini, mais les mots de longueur \(n\) forment exactement le produit cartésien \(A^n\) (3.3) : il y en a \(|A|^n\).
À retenir — Un ensemble se donne par extension (liste) ou par compréhension (propriété). Pas de doublons, pas d'ordre ; \(\varnothing\) existe et \(\varnothing \subset A\) pour tout \(A\). Un ensemble n'est pas élément de lui-même (paradoxe de Russell). \(A \subset B\) signifie « tout \(x\) de \(A\) est dans \(B\) » ; \(A = B\) se montre par double inclusion. \(\mathcal{P}(A)\) est l'ensemble de toutes les parties de \(A\) (\(\varnothing\) et \(A\) comprises) ; \(\mathcal{P}(\varnothing) = \{\varnothing\}\). \(\cup\) correspond à « ou », \(\cap\) à « et » ; \(A \setminus B\) garde ce qui est dans \(A\) sans être dans \(B\) ; \(A \,\Delta\, B = (A \cup B) \setminus (A \cap B) = (A \setminus B) \cup (B \setminus A)\). Le complémentaire n'a de sens que dans un univers \(\Omega\) ; Morgan : il échange \(\cup\) et \(\cap\). \(A \times B\) est l'ensemble des couples (l'ordre compte) ; \(A^*\) est l'ensemble des mots sur l'alphabet \(A\).
