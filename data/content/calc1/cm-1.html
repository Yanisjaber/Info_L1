Ce cours porte sur le raisonnement par récurrence. Deux passages du cahier n'étaient pas détaillés (l'étape algébrique de l'hérédité pour la somme des cubes, et le calcul final du minimum de \(f(x)=x^2+x+1\)) : ils sont complétés ici pour que chaque raisonnement soit complet.

1. Le principe de récurrence

On veut souvent démontrer qu'une propriété \(P(n)\), qui dépend d'un entier \(n\), est vraie pour tous les entiers \(n\) à partir d'un certain rang \(n_0\). La récurrence permet de vérifier une infinité de cas à partir de deux vérifications seulement.

Théorème (principe de récurrence) — Soit \((P_n)\) une propriété définie pour tout entier \(n \ge n_0\). Si :
  • Initialisation : \(P_{n_0}\) est vraie ;
  • Hérédité : pour tout \(n \ge n_0\), si \(P_n\) est vraie alors \(P_{n+1}\) est vraie,
alors \(P_n\) est vraie pour tout \(n \ge n_0\).
Démonstration (esquisse) — Par l'absurde. Supposons qu'il existe des entiers \(n \ge n_0\) pour lesquels \(P_n\) est fausse, et notons \(A\) l'ensemble (non vide) de ces entiers. Comme \(A\) est une partie non vide de \(\mathbb{N}\), elle admet un plus petit élément (bon ordre de \(\mathbb{N}\)) : notons-le \(n\).
  • \(P_{n_0}\) est vraie (initialisation), donc \(n_0 \notin A\), donc \(n \gt n_0\).
  • Ainsi \(n-1 \ge n_0\) et \(n-1 \lt n\) : par minimalité de \(n\), \(n-1 \notin A\), donc \(P_{n-1}\) est vraie.
  • Par hérédité appliquée à \(n-1\) : \(P_{n-1}\) vraie \(\Rightarrow\) \(P_n\) vraie.
  • Mais \(n \in A\), donc \(P_n\) est fausse : contradiction.
Donc \(A\) est vide : \(P_n\) est vraie pour tout \(n \ge n_0\).

2. Exemple 1 : somme des \(n\) premiers entiers

Proposition — Pour tout entier \(n \ge 1\) : \[1+2+3+\dots+n = \frac{n(n+1)}{2}.\]
Démonstration par récurrence — On note \(P_n\) la propriété « \(1+2+\dots+n = \frac{n(n+1)}{2} \) » et \(U_n = 1+2+\dots+n\).
Initialisation (\(n=1\)). \(U_1 = 1\) et \(\frac{1\times 2}{2}=1\). \(P_1\) est vraie.
Hérédité. Soit \(n \ge 1\) fixé. On suppose \(P_n\) vraie : \(U_n = \frac{n(n+1)}{2}\) (hypothèse de récurrence, HR). Montrons \(U_{n+1} = \frac{(n+1)(n+2)}{2}\) : \[U_{n+1} = U_n + (n+1) \overset{\text{HR}}{=} \frac{n(n+1)}{2} + (n+1) = \frac{n(n+1) + 2(n+1)}{2} = \frac{(n+1)(n+2)}{2}.\] On factorise par \((n+1)\) : \(P_{n+1}\) est vraie.
Conclusion. Par le principe de récurrence, pour tout \(n \ge 1\), \(1+2+\dots+n = \frac{n(n+1)}{2}\).

3. Exemple 2 : somme des \(n\) premiers cubes

Exemple central du cours : la somme des cubes des \(n\) premiers entiers est toujours un carré parfait, celui de la somme des \(n\) premiers entiers.

Proposition — Pour tout entier \(n \ge 1\), en notant \(\alpha_n = \frac{n(n+1)}{2}\) (le \(n\)-ième « nombre triangulaire », cf. exemple 1) : \[1^3+2^3+3^3+\dots+n^3 = (\alpha_n)^2 = \left(\frac{n(n+1)}{2}\right)^2.\]
Démonstration par récurrence — Notons \(P_n\) : « \(1^3+\dots+n^3 = (\alpha_n)^2\) ».
Initialisation (\(n=1\)). \(\alpha_1 = \frac{1\times2}{2} = 1\), donc \((\alpha_1)^2 = 1\), et \(1^3 = 1\). \(P_1\) est vraie.
Hérédité. Soit \(n \ge 1\) fixé, on suppose \(1^3+\dots+n^3 = (\alpha_n)^2\) (HR). On veut \(1^3+\dots+n^3+(n+1)^3 = (\alpha_{n+1})^2\). Par HR, le membre de gauche vaut \((\alpha_n)^2 + (n+1)^3\). Il suffit donc de montrer \[(\alpha_{n+1})^2 - (\alpha_n)^2 = (n+1)^3,\] soit, par différence de deux carrés, \((\alpha_{n+1}-\alpha_n)(\alpha_{n+1}+\alpha_n) = (n+1)^3\). On calcule les deux facteurs : \[\alpha_{n+1}-\alpha_n = \frac{(n+1)(n+2)}{2} - \frac{n(n+1)}{2} = \frac{(n+1)\big((n+2)-n\big)}{2} = n+1,\] \[\alpha_{n+1}+\alpha_n = \frac{(n+1)\big((n+2)+n\big)}{2} = \frac{(n+1)(2n+2)}{2} = (n+1)^2.\] Donc \((\alpha_{n+1}-\alpha_n)(\alpha_{n+1}+\alpha_n) = (n+1)(n+1)^2 = (n+1)^3\). L'égalité voulue est vérifiée : \(P_{n+1}\) est vraie.
Conclusion. Par récurrence, pour tout \(n \ge 1\), \(1^3+2^3+\dots+n^3 = \left(\frac{n(n+1)}{2}\right)^2\).
Vérification numérique (\(n=6\)) — Avec \(\alpha_6 = \frac{6\times7}{2} = 21\) et \(\alpha_7 = \frac{7\times8}{2} = 28\) :
  • \(\alpha_7 - \alpha_6 = 28-21 = 7 = n+1\) ;
  • \(\alpha_7 + \alpha_6 = 28+21 = 49 = 7^2 = (n+1)^2\) ;
  • produit : \(7 \times 49 = 343 = 7^3 = (n+1)^3\). Cohérent.

4. Rappel algébrique : factorisation de \(a^n - b^n\)

Identité classique, utile dans beaucoup de calculs. Pour \(n=3\) :

\[a^3 - b^3 = (a-b)(a^2+ab+b^2).\]

Vérification en développant le membre de droite :

\[(a-b)(a^2+ab+b^2) = a^3 + a^2b + ab^2 - a^2b - ab^2 - b^3 = a^3 - b^3\]

(les quatre termes du milieu s'annulent deux à deux).

Application (\(b=1\), \(n=4\)) — \(a^4 - 1 = (a-1)(a^3+a^2+a+1)\).
Cas général — pour tout entier \(n \ge 1\) : \(a^n - b^n = (a-b)\left(a^{n-1}+a^{n-2}b+\dots+ab^{n-2}+b^{n-1}\right)\). Cette identité se démontre elle aussi par récurrence sur \(n\).

5. Complément : signe d'une dérivée et monotonie

Pour étudier les variations d'une fonction dérivable, on étudie le signe de sa dérivée. Illustration avec l'inégalité « \(\forall x \in \mathbb{R},\ x^2+x+1 \ge 0\) » : posons \(f(x) = x^2+x+1\).

\[f'(x) = 2x+1 = 2\left(x+\tfrac12\right).\]

\(f'\) s'annule et change de signe en \(x=-\tfrac12\) :

  • sur \(\left[-\tfrac12, +\infty\right[\) : \(f'(x) \ge 0\), donc \(f\) est croissante ;
  • sur \(\left]-\infty, -\tfrac12\right]\) : \(f'(x) \le 0\), donc \(f\) est décroissante.

\(f\) décroît puis croît : elle admet un minimum global en \(x=-\tfrac12\), dont la valeur est (étape manquante dans le cahier) :

\[f\left(-\tfrac12\right) = \tfrac14 - \tfrac12 + 1 = \tfrac34.\]

Comme \(\tfrac34\) est la plus petite valeur de \(f\) sur \(\mathbb{R}\), on a \(f(x) \ge \tfrac34 \gt 0\) pour tout \(x \in \mathbb{R}\) : l'inégalité \(x^2+x+1 \ge 0\) est démontrée (et même avec une inégalité stricte).

À retenir —
  • Récurrence : trois étapes explicites, initialisation (vérifier \(P_{n_0}\)), hérédité (supposer \(P_n\), en déduire \(P_{n+1}\)), conclusion. Une hérédité qui n'utilise pas clairement l'hypothèse de récurrence n'est pas valide.
  • Formules à connaître : \(1+2+\dots+n = \frac{n(n+1)}{2}\) et \(1^3+2^3+\dots+n^3 = \left(\frac{n(n+1)}{2}\right)^2\) (la seconde est le carré de la première).
  • Astuce de l'hérédité des cubes : se ramener à une différence de deux carrés \((\alpha_{n+1})^2-(\alpha_n)^2 = (\alpha_{n+1}-\alpha_n)(\alpha_{n+1}+\alpha_n)\).
  • Factorisation : \(a^n-b^n = (a-b)(a^{n-1}+\dots+b^{n-1})\).
  • Inégalité \(f(x)\ge 0\) : étudier le signe de \(f'\), en déduire le minimum global, vérifier qu'il est \(\ge 0\).
